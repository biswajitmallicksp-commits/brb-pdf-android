OCR language files (Tesseract "tessdata_best" models, Apache-2.0 licence)

  eng.traineddata   English
  ben.traineddata   Bengali
  hin.traineddata   Hindi

To add another language (for example Tamil = tam, Odia = ori, Gujarati = guj):
download <code>.traineddata from https://github.com/tesseract-ocr/tessdata_best
and copy it into this folder. Restart PDF Workbench; it appears in the OCR dialog.
